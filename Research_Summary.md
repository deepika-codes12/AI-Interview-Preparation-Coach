# Research Summary — Three Target Roles

Research and source checks recorded on 30 October 2026. Job listings can change; recheck them before a later submission.

## IT Support / L1 Service Desk
Common responsibilities: first contact for users; troubleshoot hardware, software and network issues; log and track tickets; password reset/account unlock where authorised; document solutions; escalate unresolved issues; communicate clearly with nontechnical users.
Skills: Windows/OS basics, networking fundamentals, hardware/software troubleshooting, ticketing/documentation, security awareness, prioritisation, customer service and communication.
Verification: one official Tieto entry-level Service Desk listing was checked. It is one employer example, not a universal requirement.

## Business Analyst
Common responsibilities: gather and document requirements; analyse current/future processes and gaps; write user stories and acceptance criteria; facilitate stakeholder discussions; support Agile delivery and UAT; maintain traceability; analyse data/reporting where relevant.
Skills: requirements elicitation, stakeholder collaboration, written communication, documentation, process modelling, Agile awareness and UAT.
Verification: Caterpillar's Chennai vacancy and IIBA's Business Analysis Standard were checked. Caterpillar's vacancy requires 6+ years' experience, so it supports role activities but does not establish fresher-level requirements. IIBA describes professional BA tasks, not a job vacancy.

## QA Tester / Software Testing
Common responsibilities: review requirements; design and execute test cases; conduct functional/regression testing; log and track defects; retest fixes; support release testing; communicate defects clearly. API, database, security and performance testing depend on the role.
Skills: manual testing, SDLC/STLC, test cases and scenarios, bug lifecycle, defect reporting, Jira-style tools, and basic SQL/API awareness where relevant.
Verification:
- ISTQB CTFL v4.0.1 syllabus supports foundational testing knowledge and practices.
- Jio Associate QA Engineer listing (0–3 years) includes test plans/cases, manual and automated testing, defect tracking and regression.
- Azeus India Software Tester listing explicitly welcomes fresh graduates and includes test plans, regression, test execution and issue tracking.
- Narayana Health Junior QA Engineer listing includes broader test levels, SQL and automation expectations; do not treat all of these as universal fresher requirements.
