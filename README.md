# AI Interview Preparation Coach for Freshers

## Project question
How can AI simulate realistic interview practice for IT freshers?

## Project design
A free-tier, no-code AI-assisted preparation workflow for three target roles:
- IT Support / L1 Service Desk
- Business Analyst
- QA Tester / Software Testing

## Interview evidence
- First ChatGPT HR mock: 69, 94, 92, 61, 67; mean 76.6/100.
- Third ChatGPT IT Support scenario mock: 96, 98, 98, 97, 98; mean 97.4/100.
- Separate Gemini IT Support mock: Gemini-reported overall score 99.8/100.
These are subjective AI-generated coaching estimates, not validated hiring scores. The first and third ChatGPT rounds used different questions, so the +20.8-point difference is indicative only. Gemini's result is separate and must not be averaged with ChatGPT results.

## Tools and AI skills
The project workflow uses Perplexity for research, ChatGPT for mock interviews and feedback, Gemini for a separate model evaluation, and Canva for the visual checklist. The work demonstrates research, prompt engineering, summarisation/content generation, rubric-based evaluation, source verification/error analysis, and visual communication. A Google Sheets-style tracker is included as a no-code workflow aid; it is not a fully automated external integration.

## Automation/workflow limitation
The tracker calculates averages and highlights low scores with spreadsheet formulas and conditional formatting. The broader process still requires the user to run prompts and enter results. Do not describe it as an unattended or end-to-end AI automation.

## Multimodal/live demo
A synthetic IT support error screenshot is included and was interpreted as an image input. `Multimodal_Demo_Analysis.md` records visible facts, possible causes, safe triage and limitations. Use this asset for the live image-analysis demo; it is a training simulation, not a real incident.

## STAR answer bank
The file contains ten structured answer frameworks, not ten verified personal stories. Replace bracketed fields with genuine academic, project or teamwork examples before presenting them as personal answers.

## Responsible AI
Verify source claims, label generated questions as suggestions, disclose AI assistance according to course rules, protect private data, respect copyright and do not invent candidate experiences or results.
